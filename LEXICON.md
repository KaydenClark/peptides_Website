## Task Routing

Use `AGENTS.md` -> `RUNBOOK.md` -> this file -> the assigned stable spec.
`BLUEPRINT.md` owns cross-cutting direction and `TASKBOARD.md` is a generated
dashboard, not a second requirements store.

## Project Terms

| Term | Definition | Distinction |
|---|---|---|
| **Catalog entry** | An owner-reviewed record identifying a research material and its inquiry status. | It is not a product offer, stock statement, safety claim, or order line. |
| **Inquiry** | A nonbinding request for the operator to contact someone about selected catalog entries. | It is not an order, reservation, payment authorization, eligibility approval, or agreement. |
| **Inquiry list** | A temporary browser selection of catalog entries the visitor wants to discuss. | It must never be called a cart or display prices, quantities, or totals. |
| **Owner review** | A manual decision by the operator after an inquiry is saved. | An email-confirmation link or checkbox does not constitute qualification. |
| **Policy version** | The immutable published text shown at the time an acknowledgment is accepted. | Replacing current policy text does not rewrite historical acceptance records. |
| **Private reference material** | Local mixing and dosing documents supplied only to identify possible catalog candidates. | It is excluded from Git and must not become public website content or implementation guidance. |
| **Open for inquiries** | The owner currently permits interest inquiries about an entry. | It does not mean available, in stock, approved, or promised. |

## Workbench Terms

| Term | Definition | Distinction |
|---|---|---|
| **Spec** | Stable capability record containing scope, decisions, acceptance, verification, and evidence. | A spec is durable; a ticket is temporary execution structure. |
| **Ticket** | One bounded vertical implementation slice within a spec. | It grants no authority beyond its assigned spec and current request. |
| **Blueprint** | Product direction, invariants, non-goals, and spec catalog. | It is not a work queue or detailed evidence archive. |
| **Governance plane** | The role a claim serves as intent, canon, grounding, enduring context, actuality, or projection. | Planes classify claims in use, not files as a whole. |
